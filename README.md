## 📘 Project Overview

The Smart Hostel Management System focuses on designing a structured database to support hostel operations at Namal University.
The project transforms system requirements into a well-defined data model that ensures consistency, accuracy, and efficient data management.

---
## 🎯 Objectives
* Develop a digital system for hostel management
* Design a structured and consistent database
* Manage student records, rooms, and hostel activities
* Ensure data integrity and efficient data handling
* Support future system implementation and scalability

---

## 🧩 Problem Statement

Existing hostel operations rely on manual or loosely structured data handling, leading to redundancy, inconsistency, and inefficiency.
This project aims to design a normalized and structured database model to manage hostel data effectively.

---

## 🏗️ System Scope

The database design covers:

* Student Records
* Room Allocation and Management
* Attendance Tracking
* Entry and Exit Logs

---

## 🧱 Core Entities

* Student
* Room
* Hostel
* Attendance
* EntryExitRecord
* Staff
